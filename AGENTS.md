# module_editor — браузер и редактор файловой системы

> **Опциональный модуль.** Подключается через `src_filter` + `build_flags`.
> **Работоспособен только в составе сборки, содержащей ядро** (см. `../../TRS.md` §2.1).

Браузер LittleFS с редактором текстовых файлов (форк Ace): список файлов, создание,
удаление, загрузка, чтение и запись. Ранее входил в ядро (`core_editor`), теперь —
опциональный модуль; интегрируется с `module_macros` («Open in editor»).

- **Репозиторий:** https://github.com/Arcanum753/module_editor
- **Папка:** `src/module_editor/`
- **Флаг активации:** `-D MODULE_EDITOR`
- **Registry:** `object=module_editor`, `define=MODULE_EDITOR`, `web=1`, `loop=0` (без `namespace`/`res`/`prio`)
- **Только для платформы:** обе (ESP8266/ESP32)
- **Зависит от модулей:** —
- **Зависит от ядра:** `core_web`, `core_sys`, `core_json`

## Назначение

Браузер/редактор LittleFS (форк Ace): список, создание, удаление, загрузка,
чтение/запись текстовых файлов (`.html`, `.txt`, `.json`, `.js`), информация об
использовании ФС.

## Функциональные требования

- FR-EDITOR-1: `GET /editor/list` — список файлов; `GET /editor/fsinfo` — использование ФС.
- FR-EDITOR-2: `GET /editor/edit` — страница; `PUT /editor/edit` — создание; `DELETE /editor/edit` — удаление; `POST /editor/edit` — загрузка.
- FR-EDITOR-3: Ограничение загрузки `MAX_UPLOAD_SIZE=1 МБ`.
- FR-EDITOR-4: Интеграция с `module_macros` («Open in editor»).

## Веб-интерфейс

Страница `edit.html` (пункт меню — `web/_menu.html`), JavaScript редактора Ace
(`ace.js`, `mode-*.js`, `theme-*.js`) вендорится в модуль. Публичный маршрут —
`/editor/*`.

## Конфигурация

Собственного `config_*.json` нет.

## Слоистая структура

## Критерии приёмки

- AC-9: Редактор ФС: список, создание, редактирование, сохранение, удаление, загрузка (до 1 МБ), занятость ФС.

## Ограничения и известные проблемы

- См. OPEN-7 (каноническое описание — в `../module_rgb/AGENTS.md`): у `module_editor` нет resource-bus, модуль недоступен из макросов.
